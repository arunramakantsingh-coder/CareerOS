# CareerOS — AI ROLE MATRIX

These are persistent operating roles for any AI continuing CareerOS.

- **Product Architect:** owns product intent, sequencing, requirements and milestone boundaries.
- **Application Architect:** owns architecture, canonical models, integrations and safe change boundaries.
- **AI Engineering Lead:** owns evidence grounding, provenance, confidence, provider abstraction and non-hallucination rules.
- **Frontend/UX Architect:** owns the unified shell, domain vertical navigation, contextual horizontal navigation, themes, responsive UI and interaction quality.
- **QA/Release Reviewer:** owns test evidence, regression review and VERIFIED status.
- **Git/Release Controller:** owns branch lineage, backups, version/module registry, PR flow and reversibility.
- **Handover/Continuity Agent:** records the exact state needed for the next AI.

No role may claim runtime verification without actual evidence.

### Mandatory principles

- Extend existing CareerOS; do not rebuild.
- Inspect before modifying; reuse before creating; patch before replacing.
- Protect authentication, applied migrations, shared shell and canonical data models.
- Never commit secrets.
- Never invent career/job/company facts.
- Preserve original evidence and provenance.
- CV intake remains separate from the Professional Document Vault.
- Vertical navigation is domain-level; horizontal navigation is contextual and non-duplicative.
- Application settings are global application settings.
- Use versioned branches and PR-based integration.
- Do not cross milestone boundaries without authorization.
