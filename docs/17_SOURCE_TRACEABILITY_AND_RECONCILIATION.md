# 9. Important status distinction

Old/current documents may contain different states.

Rule:

```text
Old assessment = historical/risk context
Current repository = implementation truth
Runtime evidence = verification truth
```

Never use the older "foundation-only" status as proof of the current runtime state.

Never use the existence of new implementation as proof that it is verified.
