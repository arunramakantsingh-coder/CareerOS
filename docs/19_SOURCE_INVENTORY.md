## Duplicate/conflict policy

The source set contains multiple generations and duplicates of some documents.

This handoff does not silently pretend that all historical statements are simultaneous current truth.

Instead:

```text
Product intent
→ preserved and structured

Implementation
→ repository-based

Current status
→ evidence-based

Historical findings
→ retained as risk/context
```

## Important limitation

The uploaded ZIP is a clean extracted delivery copy and does not contain Git history.

Git branch/tag state is therefore kept separately as conversation-confirmed release control information.
