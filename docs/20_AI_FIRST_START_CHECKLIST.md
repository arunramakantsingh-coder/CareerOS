# CareerOS — AI First-Start Checklist

Any newly connected AI must perform this checklist before writing code.

## Step 1 — Identify role

Am I:

- ChatGPT Lead Architect/QA/Reviewer?
- DeepSeek Developer/Coder?
- Another AI reviewer/tester?

## Step 2 — Read the control plane

Read:

- `00_HANDOFF_INDEX.md`
- `01_ORIGINAL_PROJECT_IDEA_RECONSTRUCTED.md`
- `02_PRODUCT_VISION_AND_SCOPE.md`
- `03_VERSION_AND_RELEASE_ARCHITECTURE.md`
- `04_CORE_ARCHITECTURE_AND_FOUNDATION.md`

## Step 3 — Read the current status

Read:

- `10_CURRENT_STATUS_AND_VERIFICATION.md`

## Step 4 — Identify current branch/version

Confirm:

- branch
- commit
- tag where applicable
- local runtime status

## Step 5 — Inspect code before change

Check:

- backend
- frontend
- DB/migrations
- tests
- scripts
- Docker
- existing implementation

## Step 6 — Do not assume completion

Every feature must have evidence.

## Step 7 — Confirm product differentiator

Before touching Job Intelligence or Matching:

> Search and rank by career capability, not only job title.

## Step 8 — Confirm Skill Gap rule

Before matching work:

> Skill Match >= 60% must be visible, explainable and persisted into cumulative Skill Gap Intelligence.

## Step 9 — Confirm UI rule

Backend feature + corresponding UI + executable tests.

## Step 10 — Establish milestone

One task only.

Define acceptance criteria.

Implement.

Test.

Review.

Then continue.
