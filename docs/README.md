## Core rule

CareerOS must remain:

**CAREER-CENTRIC, NOT JOB-TITLE-CENTRIC.**

The Career Vault/Career Passport and evidence model describe the candidate. Jobs become Job DNA. Matching occurs at capability/evidence level. Hard failures remain explicit. Application content must be evidence-backed. Global mobility is a connected decision layer.

## Critical product addition

A job with **Skill Match >= 60%** is a visible high-potential opportunity.

The opportunity must show:

- Skill Match %
- matched skills/capabilities
- partial skills/capabilities
- missing skills/capabilities
- mandatory missing requirements
- transferable/adjacent capabilities
- persona relevance
- supporting evidence
- hard failures

Every missing/partial skill can contribute to a **persistent cumulative Skill Gap Intelligence record** so CareerOS can tell the user where the market repeatedly shows weaknesses in the current profile.
